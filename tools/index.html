Tester les données de REMAP.

Un favori JavaScript lancé par vous, dans votre onglet REMAP après le CAPTCHA.

  1. Installez le favori

    Faites glisser le bouton ci-dessous vers la barre de favoris de votre navigateur. Sur un appareil qui ne le permet pas, créez un favori et copiez le code fourni dans son adresse.

    Chargement du favori…

    Ne cliquez pas sur ce favori depuis Rémanence : il doit être lancé depuis la carte REMAP.

    Afficher le code du favori
  2. Ouvrez votre session REMAP

    Passez manuellement le CAPTCHA et les étapes d’accès, puis ouvrez la carte.

    Ouvrir REMAP ↗
  3. Lancez le favori dans l’onglet REMAP

    Un panneau « Rémanence · capture locale » apparaît. Affichez ensuite une série temporelle ou utilisez Refresh sur REMAP. L’outil observe les nouvelles réponses JSON reçues via fetch et XMLHttpRequest, sans provoquer de requêtes supplémentaires.

  4. Téléchargez la capture

    Le fichier contient les réponses JSON et leur chemin d’origine, sans paramètres d’URL, en-têtes ni corps des requêtes. Fermer le panneau arrête la capture et restaure les fonctions d’origine.

    Ce fichier est un échantillon technique. L’importeur Rémanence accepte déjà le CSV et le JSON documentés ; la conversion des réponses REMAP reste à adapter après examen d’une capture réelle. Une capture vide peut signifier que les données étaient déjà chargées, que le site utilise un autre mécanisme ou que le navigateur bloque le favori.

L’outil n’exécute aucune validation CAPTCHA. Il ne lit pas les réponses déjà reçues avant son activation, les WebSockets ni les réponses non JSON. Limites : 200 réponses et 20 Mo au total. Le filtrage des champs sensibles est conservateur ; examinez le fichier avant de le partager.
