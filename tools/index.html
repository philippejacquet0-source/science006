Capture des séries REMAP

Un favori JavaScript lancé par vous, dans votre onglet REMAP après le CAPTCHA.

  1. Installez ou remplacez le favori

    Remplacez l’ancien favori par la version 2 : faites glisser le bouton ci-dessous vers la barre de favoris de votre navigateur. Sur un appareil qui ne le permet pas, créez un favori et copiez le code fourni dans son adresse.

    Chargement du favori…

    Ne cliquez pas sur ce favori depuis Rémanence : il doit être lancé depuis la carte REMAP.

    Afficher le code du favori
  2. Ouvrez votre session REMAP

    Passez manuellement le CAPTCHA et les étapes d’accès, puis ouvrez la carte.

    Ouvrir REMAP ↗
  3. Lancez le favori dans l’onglet REMAP

    Un panneau « Rémanence · capture locale » apparaît. Cliquez une balise, ouvrez sa courbe, réglez la période et sélectionnez les balises voisines. Le chargement initial de la carte ne fournit pas toutes les séries. L’outil observe les réponses réseau et, si le client jQuery le permet, leur état après traitement par REMAP. Il ne provoque aucune requête supplémentaire.

  4. Téléchargez la capture

    Le fichier contient les réponses JSON, leur chemin d’origine, les noms des en-têtes (sans valeurs) et les chemins des scripts du client REMAP. Les paramètres d’URL, cookies et corps des requêtes ne sont pas exportés. Fermer le panneau arrête la capture et restaure les fonctions d’origine.

    Les réponses réseau peuvent être encodées. Rémanence les diagnostique sans les tracer. Il importe les états après traitement par le client quand des coordonnées et identifiants exploitables y sont présents. La récupération de ces états reste à vérifier sur REMAP réel ; la liste des scripts aide à identifier la conversion officielle si les réponses restent encodées. Une capture vide peut signifier que les données étaient déjà chargées, que le site utilise un autre mécanisme ou que le navigateur bloque le favori.

L’outil n’exécute aucune validation CAPTCHA. Il ne lit pas les réponses déjà reçues avant son activation, les WebSockets ni les réponses non JSON. Limites : 200 réponses et 20 Mo au total. Seules les balises dont les séries ont été consultées peuvent être analysées. Le filtrage des champs sensibles est conservateur ; examinez le fichier avant de le partager.
