Collecter les données REMAP.

Le collecteur s'exécute dans votre onglet REMAP, après le passage manuel du CAPTCHA. Les fichiers sont enregistrés dans le dossier que vous choisissez. GitHub ne réalise aucune collecte.

Installer le favori de collecte

Dans Chrome sur ordinateur, faites glisser ce lien vers votre barre de favoris :

Bouffi · collecteur REMAP

Lancez ensuite ce favori depuis la carte REMAP. Il ne démarre pas depuis cette page. Si le glisser-déposer n'est pas disponible, créez un favori et copiez le code du favori dans son adresse.

Copier le code du favori

Nouvelle collecte

  1. Ouvrez REMAP, passez vous-même le CAPTCHA et accédez à la carte.
  2. Réglez la période avec le curseur REMAP, puis lancez le favori « Bouffi · collecteur REMAP ».
  3. Choisissez « Pilote · 2 balises » pour vérifier l'accès, ou « Nouveau réseau complet », puis un dossier de sauvegarde. Le plan de collecte est alors figé.

Reprendre une collecte interrompue

  1. Installez ce favori à la place de l'ancien. Fermez l'ancien panneau de collecte ; si une requête reste bloquée, rechargez REMAP et repassez manuellement le CAPTCHA si demandé.
  2. Lancez le favori, puis cliquez sur « Reprendre un dossier existant ».
  3. Sélectionnez directement le dossier contenant manifest.json et les lots, et non son dossier parent.
  4. Attendez la vérification locale, puis cliquez sur « Démarrer / continuer ».

La période et les balises viennent du manifeste sauvegardé ; le curseur REMAP n'a pas besoin d'être replacé. Les lots valides sont conservés sans nouvelle requête. Les lots absents ou invalides sont demandés à nouveau ; les fichiers invalides sont copiés avant remplacement. Une copie du manifeste précédent est conservée.

Fonctionnement et limites

Les requêtes sont successives, par lots de dix balises et fenêtres de sept jours au plus, avec une pause de trois secondes entre les lots. Ces paramètres ne sont pas des limites officielles du service. Pause et Fermer interviennent après la requête en cours. Une expiration de session peut imposer un nouveau CAPTCHA, qui reste manuel.

Les intervalles sont semi-ouverts. Les absences ne sont pas remplacées par des zéros. Le manifeste distingue les lots terminés, les balises sans série et les erreurs. Un lot validé localement ne prouve pas la disponibilité de toutes les mesures côté service.

Cet outil est celui préparé pour la collecte de l'instantané utilisé par Bouffi. La vérification locale de reprise a porté sur 469 lots d'une collecte réelle interrompue ; son exécution après relancement dans Chrome reste à vérifier. Le collecteur dépend du client REMAP chargé et peut cesser de fonctionner si celui-ci évolue. Les nouveaux fichiers ne sont pas ajoutés automatiquement à l'instantané affiché par Bouffi.

L'authentification reste dans le client REMAP. Aucun jeton ni cookie n'est exporté. Télécharger le script autonome.
